# JEI++

JEI++ adds three small client-side quality-of-life improvements to JEI:

- A cycling recipe slot with multiple alternatives can be opened as a paged ingredient directory.
- The recipe page row and the recipe-category row each respond to the mouse wheel independently.
- Opening a bookmarked recipe keeps the normal recipe/usage lookup and lets JEI's **Bookmark output as recipe** and **Prioritize bookmarked recipes** settings keep the bookmarked recipe at the front.

The Forge build targets Minecraft 1.20.1. The `1.21.1` branch targets NeoForge for Minecraft 1.21.1. JEI is an optional client dependency; the addon does not add gameplay content.
